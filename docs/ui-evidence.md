# Renderer evidence

## Delivered

React default `App` accepts an injected bridge for DOM tests and otherwise uses `window.rift`. No Node imports, network requests, provider task imports, or renderer token handling. The workspace starts empty.

- Charcoal Operate workspace, native Segoe UI/SF font stack, restrained amber, compact category/project tree, queue and four-column board, right-hand editor.
- Category/project creation and editing. Project archive/restore retains descendants; task deletion requires a second explicit action.
- Task title, project, notes, status, priority, due date and Today pin; completion timestamps maintained on status changes.
- Today/all/project views; title/notes search; list/board layout; labeled forms; trapped dialog keyboard focus; Escape closes when not saving and restores trigger focus.
- Login/check-sign-in, missing-gh explanation, loading/retry, offline identity disclosure, local disconnect, error and empty states.
- Native repository/terminal/directory actions use the exact bridge contract. Export/import invokes main-process dialogs; import requires explicit replacement consent.
- All mutations await persisted `save()` results. A shared synchronous lock prevents overlapping saves/import/native operations. Saving fields are disabled. Failed drafts remain editable; failed status updates retain persisted state.
- Without preload, an explicit browser-preview banner discloses memory-only operation. No production sign-in is simulated; native actions are disabled. Refresh discards preview data.

## Boundaries

Only renderer source, root HTML, and this evidence document were authored by the UI task. No package/config/backend changes or git writes. Build outputs are generated by the existing build script. No optional sample loader, drag-and-drop, git-status view, installers, sync, or provider issue fetching was added. Project archive is the non-destructive container-management path; category deletion is intentionally not offered.
